# Password Strength Checker 🔐

This project is a simple yet effective Python-based tool that evaluates the strength of a given password based on key security criteria. It was developed as part of the Hack Secure Internship for educational and demonstration purposes.

## 📌 Features

- Checks for:
  - Minimum length (8 characters)
  - Use of uppercase and lowercase letters
  - Inclusion of digits
  - Use of special characters
- Categorizes password strength as:
  - **Weak**
  - **Moderate**
  - **Strong**

## 🧠 How It Works

Each criterion adds to a score out of 5. The total score determines the strength category:

- `<= 2` ➡️ Weak  
- `3 or 4` ➡️ Moderate  
- `5` ➡️ Strong
